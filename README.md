# 家庭辦公室第一版

單一 HTML、原生 JavaScript ES Modules 與 Three.js 0.160.0 的本機原型。所有初始財務數字都是**範例**，不連接銀行、券商、雲端或多人同步服務。

## 啟動

請在此目錄執行：

```bash
python3 -m http.server 8000
```

開啟 <http://localhost:8000/>。請勿以 `file://` 直接雙擊作為正式使用方式，因為 ES Modules 與 localStorage 在該模式的行為不可靠。

## 已完成

- 家庭總覽、五座可選取的程式生成黏土島、全景／鳥瞰／日夜切換。
- 可調整生活費、通膨、可用股息率與 8／10 年情境，即時計算目標本金與缺口。
- 資產、教育、旅行、退休與健康五個主題的現況／目標／差距／討論／下一步。
- 討論與待辦的新建、狀態更新、完成勾選與 localStorage 保存。
- JSON 匯出／欄位驗證後匯入／還原範例資料。
- reduced-motion 停止平滑相機飛行；CDN、WebGL 或本機儲存失敗時保留文字操作介面。

## 已知限制

- 使用 jsDelivr CDN，離線或 CDN 被封鎖時 3D 會降級為文字版。
- localStorage 只在相同協定、主機與連接埠的瀏覽器來源保存，不是多人同步。
- 本版沒有真實帳戶、即時匯率、稅務計算、保單分析或投資建議。
